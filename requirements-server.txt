# Hosted Trinetra MCP server.
#
#   requirements-mcp.txt     the MCP server itself (protocol, market data, maths)
#   + this file              what hosting adds: HTTP transport, Postgres, OAuth
#
# requirements.txt is NOT included anywhere here — the LangChain/LangGraph stack
# belongs to the legacy CLI and never ships to the server.
#
#   pip install -r requirements-server.txt

-r requirements-mcp.txt

# Every dependency carries a major-version upper bound. What was tested has to
# be what runs: a major release landing between a green test run and a deploy is
# how this service breaks without anyone changing a line of code.

# --- HTTP transport ---
# No lower bound: mcp declares what it needs, and inventing a floor we have not
# tested against is its own risk. The upper bound is the point.
uvicorn[standard]<1
starlette<1

# --- Database ---
sqlalchemy>=2.0,<3
alembic>=1.13,<2
psycopg[binary]>=3.1,<4

# --- OAuth token verification ---
pyjwt[crypto]>=2.8,<3
cryptography>=42,<48

# --- Broker SDKs ---
# Only the hosted server places real orders, so these live here rather than in
# requirements-mcp.txt. Leaving them out is not a degraded experience — it is a
# server that cannot trade at all, and the failure only shows up the first time
# a user tries. tests/test_packaging.py and the preflight both check for them.
growwapi>=1.5,<2
pyotp>=2.9,<3
kiteconnect>=5.0,<6
